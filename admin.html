ตั้งค่า Supabase ครั้งแรก (ทำครั้งเดียว)
  1. สมัคร supabase.com แล้วสร้างโปรเจกต์ใหม่ (ฟรี)
  2. เมนู SQL Editor → วาง SQL ด้านล่างทั้งหมด → กด Run
  3. เมนู Authentication → Users → Add user → อีเมล ใส่รหัสผ่านของคุณ (ติ๊ก Auto confirm)
  4. Authentication → Sign In / Providers → ปิด "Allow new users to sign up"
  5. Project Settings → API คัดลอก Project URL และ anon/publishable key ไปใส่ SB ที่หัวไฟล์ admin.html และ index.html
